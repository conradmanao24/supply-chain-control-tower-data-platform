# Engineering Evidence

This directory is reserved for reproducible evidence generated by project verification.

Evidence may include validated command output, row-count snapshots, reconciliation summaries, test results, architecture diagrams, and screenshots that are safe for a public repository.

Do not store secrets, credentials, local `.env` values, database backups, database files, or other sensitive runtime artifacts here.

Evidence should support claims made in the README and phase reports; no benchmark or reliability claim should be fabricated.
