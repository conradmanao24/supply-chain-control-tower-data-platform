# Bootstrap

This directory contains the repository-owned setup paths for the Supply Chain Control Tower.

## Exact portfolio bootstrap

The final v1.0 platform is reproduced from the frozen SQL Server baseline through **2026-09-15**.

Expected local artifact:

`data/baselines/full-master/wwi-full-master-2026-09-15.bak`

Pinned verification:

- bytes: `1662111744`
- SHA-256: `1F779A53D9AE1E5B90F2C62BA74D3E48E5FED0F75096E5EC798A09ABF04DEE30`

The backup is intentionally excluded from Git history. When it is absent locally, the bootstrap downloads it from the `v1.0-data-baseline` GitHub Release and verifies its size, SQL Server backup signature, and SHA-256 before restore.

After copying `.env.example` to `.env`, set local database/service passwords and generate the Airflow secrets before bootstrap.

Required local password values:

```text
MSSQL_SA_PASSWORD
DWH_PASSWORD
AIRFLOW_DB_PASSWORD
WWI_SOURCE_PASSWORD
WWI_EVENT_PASSWORD
```

Generate `AIRFLOW_FERNET_KEY`:

```powershell
python -c "import base64,secrets; print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode())"
```

Generate separate values for `AIRFLOW_API_SECRET_KEY` and `AIRFLOW_JWT_SECRET`:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

After the Airflow API server starts, the UI password generated by Airflow SimpleAuthManager can be read locally with:

```powershell
docker compose exec -T airflow-api-server cat /opt/airflow/simple_auth_manager_passwords.json.generated
```

The Airflow username is `AIRFLOW_ADMIN_USERNAME` from `.env`. No Airflow UI password is committed to the repository. If the API server container is recreated, run the command again to read the current password.

Then run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap/bootstrap-platform.ps1
```

The bootstrap performs the existing validated project steps in dependency order:

1. validate and restore the frozen SQL Server baseline;
2. recreate project-owned SQL Server extraction, Service Broker, publication, deadline, and realtime integration objects;
3. build the project-owned Airflow/dbt image;
4. start the PostgreSQL warehouse and Airflow metadata database;
5. create the staging contract;
6. run the full business staging load through the 2026-09-16 cutoff;
7. create the full 5-minute telemetry aggregates through the same cutoff;
8. run the initial dbt warehouse build;
9. provision pipeline state, source frontier, realtime projections, SSE, alerts, backfill state, quality persistence, and serving indexes;
10. start the complete Docker runtime;
11. unpause the three repository DAGs and validate Airflow imports.

The runtime source simulator then advances complete business days after the frozen baseline and publishes the durable source frontier. The Airflow incremental DAG follows that frontier.

The Vite frontend is intentionally outside Docker Compose and is started separately:

```powershell
Set-Location frontend
npm ci
npm run dev
```

## Official Microsoft source-only bootstrap

For source acquisition/restoration without building the final portfolio platform, the source bootstrap and audit path remains available.

Acquire the official Microsoft backup:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap/download-wwi.ps1
```

Restore and validate only the official WWI source:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap/bootstrap-source.ps1
```

This source-only path does **not** by itself provision the analytical warehouse, realtime plane, alerts, or final 2026 portfolio state.

## Files

- `bootstrap-platform.ps1` - final frozen-baseline platform bootstrap
- `download-portfolio-baseline.ps1` - GitHub Release download + signature/size/SHA-256 validation
- `restore-portfolio-baseline.ps1` - auto-download + checksum-backed frozen baseline restore
- `provision-source-integration.ps1` - idempotent SQL Server project integration
- `provision-warehouse.ps1` - PostgreSQL pre-load/post-load migrations
- `download-wwi.ps1` - official Microsoft source acquisition
- `preflight-source.ps1` - Docker/config/port safety gate
- `restore-wwi.ps1` - official source restore
- `validate-source.ps1` - restored-source validation
- `bootstrap-source.ps1` - official source-only orchestration
- `lib.ps1` - shared bootstrap helpers

## Public artifact boundary

The frozen 2026 baseline is not committed to Git history. It is published separately as the `v1.0-data-baseline` GitHub Release asset and is downloaded automatically by the full platform bootstrap when absent.

Microsoft WideWorldImporters remains the upstream sample-data source. See `THIRD_PARTY_NOTICES.md` and `THIRD_PARTY_LICENSES/MICROSOFT-SQL-SERVER-SAMPLES-MIT.txt`.
